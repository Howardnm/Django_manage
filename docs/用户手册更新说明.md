本次已按当前工作区的页面模板、前端交互和后端业务链路重写用户操作手册，提供 [Markdown 阅读版](用户操作手册.md) 和 [Word 下载版](用户操作手册.docx)。正文共 27 章，另附操作入口速查，保留四张原有关系图。下面的问题记录用于后续排查；本次没有修改业务代码。

## 主要更新

| 业务 | 更新后的操作口径 |
|---|---|
| 登录和授权 | 使用工号登录；邮箱用于注册和找回密码。自助注册后仍需管理员补齐工号、内部角色及权限 |
| 项目与档案 | 区分创建必填项、自动负责人、创建后自动档案与后补信息；补齐节点迭代、成员百分比及小数尺度绩效算法 |
| 新建试产 | **项目详情 → 查看配方 → 配方过程 → 试验排产 → 创建工单 → 工单详情 → 提交审批**。排产总览用于查询；同一实验单的全部版本均须检查 |
| 客样 | **配方过程 → 新增客样 → 创建竞品工单**先产生草稿，再到工单详情提交审批；跳过挤出 |
| 排产和挤出 | 区分只读排产日历与排产工作台；“领取”是排期操作，不等于分配操作员。推荐从工单详情开始挤出以联动配色 |
| 组合物料 | 补充单版本组合模式、替代组、按用途可能性、100%检查、成本和 SAP 概率差异；保存后不能任意切换模式 |
| 配色 | 按 **G/25KG** 输入克数，最多三位小数；份数＝克数÷250。分别说明单版、批量、覆盖保存的范围 |
| 注塑及测试 | 按实际矩阵录入产出和合格数量；区分部分回写、完整回写与手动结束，说明库存状态变化 |
| 正式测试指标 | **项目详情 → 查看配方 → 测试结果 → 均值回写 → 确认保存**；工单来源值与手动正式指标分别保存 |
| 测试更正 | 负责人在配方过程的测试结果中选择工单编号，再点 **测试退回**。退回不会自动撤销已完成工单、恢复样条或重算正式均值 |
| SAP | 区分真实 SAP BOM 发布、本地样品 SAP 入库登记和 SAP 实际库存过账；补齐工厂、用途、可选 BOM、替代信息、包装袋、检查及查询核对 |
| 数据导入 | 材料及配方的编辑导入在 **确认选择** 时立即落库；关闭页面不会撤销。配方导入可影响整个目标实验单 |
| 审批和表单 | 依据真实签收、处理、移交、退回及重提按钮；说明多步骤填写、附件即时保存、删除模板的历史影响 |
| 官网与 MCP | 保留电子手册页面下线、CRM 调用目录 API 的现状；区分目录服务密钥、个人 MCP Key 与站内 AI 占位入口 |

## 审查范围和证据边界

按业务域交叉检查项目自有 Python、HTML 和 JavaScript，覆盖 21 个应用目录、主项目路由、`common_utils`、共享模板和前端脚本。核对内容包括模型、表单、视图、服务、权限、状态机、信号、工作流回调、菜单、页面按钮及相关现有测试。大型管理命令结合结构、调用链和测试审阅；第三方 SDK、压缩库、生成的迁移、日志和用户上传资料不作为逐字审读范围。

操作步骤依据“菜单入口 → 页面按钮 → 参数校验 → 服务动作 → 下游结果”整理。当前菜单启用状态、账号权限及业务配置由部署数据库决定，本次没有以真实账号逐页点击验收，也没有连接业务数据库、执行 SAP 写入或宣称现有 Django 测试通过。以下“确认”指源码能确认的实现差异；运行表现、并发行为和外部 SAP 结果仍需受控环境验证。
