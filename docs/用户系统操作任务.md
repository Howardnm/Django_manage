# 项目管理系统用户操作任务与端到端测试手册

> 文档版本：1.1  
> 适用系统：Django_manage 项目管理系统  
> 更新日期：2026-09-18  
> 配套文档：[用户操作手册](用户操作手册.md)  
> 适用对象：新用户、业务培训人员、系统管理员、验收测试人员

---

## 1. 文档目的

本手册把系统功能组织成一组按数据依赖递进的可执行任务。主线从客户和 OEM 开始，依次建立成品材料、研发项目、实验配方与 BOM、试产工单和排产任务，再进入生产、测试、结果回写与项目闭环。用户按顺序完成后，应能理解“前一步创建什么、后一步在哪里使用”，并同时完成一次覆盖主要模块的端到端测试。

本手册同时用于验证：

- 页面入口、列表搜索、筛选、分页和详情跳转；
- 角色权限、部门/工作组数据范围和对象权限；
- 客户、OEM、成品、原材料、工艺、模具和测试标准等前置数据；
- 项目、阶段节点、成员、配方和工单之间的数据关联；
- 审批、表单、附件和通知等跨模块能力；
- 配色、挤出、颗粒分拨、注塑、样条库存、材料测试和配方回写；
- 成本、状态、看板、报表和产品电子手册的数据一致性；
- 必填校验、缺价、权限不足、重复提交和锁定限制等异常场景。

> 本手册优先在测试环境或专用测试组织中执行。不要在正式项目、正式库存或真实客户数据上练习删除、终止、SAP 入库、手动完成并回写等高影响操作。

## 2. 执行约定

### 2.1 任务状态

每项任务完成后勾选一种状态：

- [ ] **通过**：步骤全部完成，实际结果与预期一致。
- [ ] **失败**：能够执行，但结果与预期不一致。
- [ ] **阻塞**：缺少权限、配置、外部服务或前置数据，无法继续。
- [ ] **不适用**：当前环境未启用该模块或明确不在本次验收范围。

失败或阻塞时至少记录：任务编号、操作账号、业务对象编号、发生时间、页面提示、截图/附件及复现步骤。

执行前确定本次批次号：

## 3. 总体任务路线

```text
A 系统前置：账号/权限、分类、流程、原材料价格、工艺、模具
    ↓ 前置数据检查通过后进入业务主线
B 客户/OEM
    ↓ 输出客户和 OEM
C 成品材料
    ↓ 输出待研发/待验证的成品牌号
D 项目
    ↓ 在项目中关联客户、OEM、成品材料、成员和节点
E 配方/BOM
    ↓ 在项目节点下关联原材料、价格、工艺和预研数据
F 工单/审批/排产
    ↓ 选择配方版本、模具、测试项、操作员和时间
G 配色/挤出/库存/注塑/测试/回写
    ↓ 形成实物与测试结果闭环
H 项目闭环/成品发布/报表
    ↓
I–K 扩展、异常、安全和受控高风险验证
```

### 3.1 数据前置关系

| 即将操作的对象 | 必须先准备的数据 | 在哪里准备 | 本阶段完成后输出 |
|---|---|---|---|
| 客户 | 测试账号、组织权限、销售人员 | 阶段 A | 客户、OEM、联系人和销售归属 |
| 成品材料 | 材料类型、应用场景、材料特性、测试标准 | A05 | 待研发或待验证的成品牌号 |
| 项目 | 客户/OEM、成品材料、项目等级、业务板块、负责人、审批流程 | B01、C01、A05、A06 | 项目编码、成员、当前节点和商务档案 |
| 配方 | 项目及当前节点、预研项目、原材料、历史价格、工艺方案 | D01–D05、A08–A10 | 实验单号、配方版本、BOM 和预测成本 |
| 工单与排产 | 可用配方版本、工艺、模具、测试项目、操作员、审批人 | E01–E04、A05、A06、A10、A11 | 已审批工单、挤出排期和执行任务 |
| 生产与测试 | 已排产工单、色粉 BOM、库存去向、注塑模具 | F01–F05、E04 | 颗粒/样条库存、测试结果和配方回写 |

> 客户、OEM 与成品材料不一定在各自的主数据页面直接绑定。它们在阶段 D 的项目及项目商务档案中建立业务关系：一个项目选择一个目标成品材料，并在商务档案中关联客户和 OEM。

### 3.2 开始前数据盘点

由 `ADMIN` 组织各角色先完成下表。已有数据可以复用，但必须记录实际名称或编号；缺失项应在阶段 A 新建，不能跳过后在配方或排产页面临时猜选。

| 前置项 | 本次使用的数据/编号 | 负责人 | 状态 |
|---|---|---|---|
| 测试账号、部门、工作组和角色 |  | `ADMIN` | [ ] 就绪 |
| 材料类型、场景、特性和测试标准 |  | `ADMIN` | [ ] 就绪 |
| 项目等级、业务板块和客户意见类型 |  | `ADMIN` | [ ] 就绪 |
| 项目/工单/表单审批流程及审批人 |  | `ADMIN` | [ ] 就绪 |
| 原材料 A、原材料 B、色粉 C |  | `RD` | [ ] 就绪 |
| 各原材料的历史价格与工厂缺价样本 |  | 价格管理员 | [ ] 就绪 |
| 挤出机台、螺杆和工艺方案 |  | `PROCESS` | [ ] 就绪 |
| 可用模具与维护中模具 |  | `INJECTION` | [ ] 就绪 |

### 3.3 执行规则

- 阶段 A 是管理员和各专业角色共同完成的数据准备，全部就绪后再进入阶段 B。
- 阶段 B–H 是一条连续主链，必须按编号顺序执行，不要为后续步骤另选无关数据。
- 每次选择关联对象时，优先用批次号搜索，并把页面显示的编号记录到“输出数据”中。
- 当前阶段的完成门槛未满足时，停止后续操作并标记“阻塞”，不要使用临时数据绕过。
- 阶段 I 为扩展流程；阶段 J 为异常和安全验证；阶段 K 仅在测试环境并经负责人确认后执行。

## 4. 阶段 A：执行准备与系统前置数据

**本阶段目标**：把业务主线会引用的账号、枚举、流程、原材料、价格、工艺和模具一次准备完整。

**完成门槛**：A01–A11 均通过；阶段 3.2 的前置项全部填写实际名称或编号并勾选“就绪”。未就绪的数据应在本阶段补建。

### A01 登录和首次检查

**执行角色**：所有内部账号  
**操作入口**：`打开管理员提供的系统地址。`

1. 输入邮箱、密码和图形验证码。
2. 登录后确认进入首页。

5. 返回首页，打开左侧导航和右上角通知铃铛。

**预期结果**：登录成功；个人资料和组织归属正确；菜单与账号职责匹配；通知只能看到当前账号的数据。

## 14. 受控高风险任务

以下任务不属于普通用户的必做练习。只有在测试环境、专用数据和业务负责人授权下执行。

### K01 SAP 入库

**风险**：可能形成正式库存记录或调用外部系统。  
**操作入口**：`成品颗粒库存 → 测试批次详情 → “SAP 入库”。`

1. 确认当前环境允许测试入库，且使用专用 SAP 物料号、批次和库位。

3. 提交一次，不重复点击。

**预期结果**：只影响专用测试批次；成功/失败反馈清晰；重复入库受到限制。

**结果**：- [ ] 通过 - [ ] 失败 - [ ] 阻塞 - [ ] 不适用

### K02 手动完成并回写

**风险**：允许测试项目不完整并结束任务。  
**前置条件**：使用独立测试工单，故意保留一个非关键测试项为空。

1. 填写备注说明缺项原因。
2. 点击“手动完成并回写”。
3. 核对任务结束状态和已填写数据的回写结果。
4. 确认未填写项没有生成虚假结果。

**预期结果**：仅回写已有数据；缺项保持可识别；操作人和备注可追溯。

### K03 项目终止

**风险**：会改变项目生命周期并删除后续未开始节点。  
**前置条件**：只使用 `批次号-终止验证项目`。

1. 在当前节点发起客户意见/终止操作。
2. 选择测试意见类型，填写终止原因。
3. 提交前记录全部节点。
4. 确认终止后项目状态和剩余节点。

**预期结果**：项目终止原因可追溯；后续未开始节点按规则处理；其他项目不受影响。

**结果**：- [ ] 通过 - [ ] 失败 - [ ] 阻塞 - [ ] 不适用

**风险**：删除后可能无法恢复。  
**前置条件**：对象名称带当前批次号，且确认未被正式流程引用。

3. 尝试删除已被引用的原材料或配方，确认系统阻止后立即停止。

**预期结果**：未引用的专用测试数据可按权限删除；被引用数据受到保护；删除范围准确。
