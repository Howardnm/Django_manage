权限管控中心

本系统采用 L1~L5 五层安全模型，前三层为准入控制（决定你能进哪些模块做什么操作）， 后两层为数据隔离（决定你能看到哪些数据）。全部配置均可在 Admin 后台动态管理，无需改代码。

五层安全架构

L1 角色白名单 ModuleAccessConfig.role_groups 你是哪个角色？→ 能进哪些模块
L2 用户等级 ModuleAccessConfig.min_level 你的职级够吗？
L3 Django 权限码 [L3 权限容器] 权限角色组 你能做 view / add / change / delete 吗？
准入边界 — 通过以上三层后进入模块
以下两层控制模块内能看到哪些数据
L4 部门隔离 ModuleAccessConfig.enforce_dept_isolation 只能看本部门拥有的数据
L5 工作组隔离 ModuleAccessConfig.enforce_group_isolation 只能看本工作组拥有的数据

配置步骤

  1. 定义有哪些用户角色 进入 [L1] 用户角色， 系统中的每个身份对应一条记录（如 ENGINEER 研发工程师、SALES 业务员）。 可随时新增或禁用角色。
  2. 把角色归入分组 进入 [L1 分组] 角色分组， 将多个角色归入一个命名分组（如 TECH_CORE = ENGINEER + PROCESS_ENGINEER + ADMIN）。 后续模块权限配置引用的是分组，而非单个角色。
  3. 给每个业务模块勾选允许的角色组 进入 [L1~L5] 模块权限配置， 每条记录对应一个业务模块（如 formula 实验配方库），勾选其 role_groups 即决定谁能访问。 同时可配置 L2 最低等级、L4 部门隔离、L5 工作组隔离开关。
  4. 给用户分配角色 + L3 权限组 进入 用户管理，编辑具体用户：
    • 用户角色 (user_type) → 决定 L1 准入
    • 组 (groups) → 勾选 [L3 权限容器] 中的角色组，决定 L3 操作权限
  5. 管理侧边栏菜单 进入 [菜单] 侧边栏模块， 菜单的 URL 和结构由 menu_modules.py 代码定义， Admin 中可调整排序、临时隐藏、对子项做 L1 角色覆盖。

部署命令

以下命令在项目部署或新增业务模块时使用：

python manage.py sync_rbac_modules

扫描所有 app mixin 中声明的 module_code，自动在 ModuleAccessConfig 表中创建缺失记录。

python manage.py sync_menus

从 menu_modules.py 代码定义同步菜单到 SidebarModule / SidebarSubItem 表。

python manage.py init_rbac

一键执行以上两步（含 --dry-run 预览模式）。
